# 21. Future Version (Post-MVP Roadmap)

Advanced capabilities to add after the MVP proves value.

## Phase 2 — External & financial depth
- **Client portal** and **Vendor portal** (with their own dashboards, invoice submission, sign-offs).
- **Purchase requests → POs**, **petty cash**, **advances**, **reimbursements** full flows.
- **Payroll integration** and labor-cost allocation into profitability.
- **Tax engine** (multi-rate VAT/GST), multi-currency.
- **Advanced approvals:** parallel + quorum, conditional routing by multiple fields, auto-escalation with SLAs and backups.
- Multi-channel notifications: **SMS, WhatsApp, Slack, Teams**.

## Phase 3 — Intelligence & UX
- **AI features:** meeting summaries, project summaries, risk detection, finance anomaly detection, workload suggestions, deadline prediction, smart search, smart report generation (Claude API).
- **Gantt charts + critical path**, resource leveling.
- **Mobile apps** (iOS/Android) with offline + push.
- **Calendar integrations** (Google/Outlook), email-to-task.
- **Custom dashboards & report builder** (drag-and-drop widgets).

## Phase 4 — Scale & enterprise
- **Multi-tenancy / multi-company** with isolation and per-tenant config.
- **SSO/SAML/OAuth**, SCIM provisioning.
- **Advanced RBAC** with custom roles and fine-grained field permissions.
- **Public API + webhooks**, marketplace integrations (accounting tools, CRMs).
- **Compliance certifications** (SOC 2, ISO 27001), advanced data residency.
- **Forecasting & portfolio analytics**, scenario planning.
- **Workflow/no-code automation builder** (if-this-then-that across modules).
