# 12. Dashboard and Reporting

Role-specific dashboards plus a shared reporting engine. All reports respect role + department scope and can be exported (PDF/Excel/CSV) subject to [export restrictions](14-audit-and-security.md).

## Role dashboards
| Dashboard | Highlights |
|-----------|-----------|
| **CEO / Owner** | Company KPIs: active projects, portfolio health, revenue vs cost, cash flow, profitability, top risks, pending high-value approvals. |
| **Project Manager** | My projects' health, milestone progress, overdue tasks, budget vs actual, risks/issues, team workload. |
| **Finance Manager** | Budgets vs actual, receivables/payables, overdue payments, P&L, cash flow, pending financial approvals. |
| **Department Head** | Department projects, staff workload, department budget, pending approvals, performance. |
| **Employee** | My tasks, deadlines, time logged, my requests, my meetings. |
| **Client** | Their project progress, milestones, invoices/payments, upcoming meetings, shared docs. |
| **Admin** | User/role activity, system health, pending onboarding, petty cash. |

## Reports
- **Project progress** — % complete, milestones, schedule variance.
- **Finance** — income, expenses, balances by period.
- **Budget vs actual** — per project/department, variance %.
- **Department performance** — output, on-time %, budget adherence.
- **Employee workload** — assigned vs capacity, utilization.
- **Task completion** — done vs planned, cycle time.
- **Approval pending** — items awaiting action, aging, by approver.
- **Meeting report** — meetings held, action-item completion.
- **Expense report** — by project/department/category/vendor.
- **Profitability** — revenue − cost per project/client/department.
- **Audit report** — actions, approvals, changes over a period.

## Reporting features
- Filters (date range, department, project, status), drill-down, saved/scheduled reports, **AI smart report generation** (natural-language → report). See [Automation](15-automation-and-ai.md).
